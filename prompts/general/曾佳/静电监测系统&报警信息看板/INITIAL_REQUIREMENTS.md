# 静电监测系统和报警信息看板初始需求

## 1. 项目概述

静电监测系统和报警信息看板是一个用于实时监测、分析和管理静电设备运行状态的系统。该系统能够实时采集静电设备的运行数据，检测超标情况，生成报警信息，并通过可视化界面展示给用户，帮助用户及时发现和处理静电设备异常。

## 2. 功能需求

### 2.1 静电监测系统

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|-------|
| 设备监控 | 实时显示所有静电设备的运行状态，包括车间、责任人、设备编码、阻值、超标次数等信息 | 高 |
| 多通道监测 | 支持一路和二路通道的独立监测和数据展示 | 高 |
| 状态分类 | 设备状态分为正常、超标、异常等，并通过不同颜色标签标识 | 高 |
| 数据筛选 | 支持按车间、线别、设备状态、时间范围等条件筛选设备数据 | 高 |
| 综合搜索 | 支持按设备编号、责任人、线别、设备名称进行综合模糊搜索 | 高 |
| 地域筛选 | 支持按地域（HN、SZ）筛选设备数据 | 中 |
| 超标记录 | 显示设备的超标次数，支持点击查看详细超标记录 | 高 |
| 超标详情 | 支持查看超标记录的详细信息，包括报警信息、处理状态、改善情况等 | 高 |
| 超标次数详情 | 支持查看超标次数的详细统计，包括超标时间、持续时间、最大阻值等 | 中 |
| 数据排序 | 支持按各种字段进行排序，默认按超标次数降序排序 | 中 |
| 分页显示 | 支持分页显示设备列表，可调整每页显示数量 | 中 |

### 2.2 报警信息看板

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|-------|
| 报警列表 | 显示所有报警信息，包括PC编号、MAC地址、位置、责任人、报警信息等 | 高 |
| 报警类型标签页 | 按报警类型分类显示报警信息，支持切换查看不同类型的报警 | 高 |
| 报警筛选 | 支持按报警类型、处理状态、时间范围、关键词等条件筛选报警信息 | 高 |
| 报警统计 | 显示各类型报警的数量统计 | 高 |
| 报警编辑 | 支持编辑报警信息，包括PC编号、MAC地址、位置、责任人等 | 中 |
| 报警详情 | 支持查看报警的详细信息，包括创建时间、更新时间、解决时间等 | 高 |
| 处理状态更新 | 支持将未处理的报警标记为已处理 | 高 |
| 数据排序 | 支持按各种字段进行排序 | 中 |
| 分页显示 | 支持分页显示报警列表，可调整每页显示数量 | 中 |

### 2.3 报警规则管理

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|-------|
| 规则制定 | 支持制定报警规则，包括小时超标次数、超标持续时间等阈值设置 | 中 |
| 规则修改 | 支持修改现有报警规则，需要密码验证 | 中 |
| 规则应用 | 支持应用新的报警规则 | 中 |
| 规则列表 | 显示所有报警规则的制定时间、规则编码、规则内容等 | 中 |

### 2.4 系统管理

| 功能模块 | 功能描述 | 优先级 |
|---------|---------|-------|
| 用户认证 | 支持密码验证，用于保护敏感操作 | 中 |
| 推送信息 | 支持查看推送的报警信息 | 中 |
| 用户问候 | 显示用户问候信息，提供友好的用户体验 | 低 |

## 5. 界面设计需求

### 5.1 整体风格

- 采用现代科技风格设计，以深色背景为主，搭配鲜明的状态颜色
- 界面简洁明了，信息层次清晰
- 使用卡片式布局，增强视觉层次感
- 加入适当的动画效果，提升用户体验

### 5.2 颜色方案

- 正常状态：绿色
- 超标状态：黄色
- 异常状态：红色
- 已处理报警：绿色
- 未处理报警：红色
- 主色调：蓝色系
- 辅助色：橙色系

### 5.3 布局要求

- 顶部区域：包含系统名称、返回按钮、用户问候信息
- 查询区域：包含日期筛选、车间下拉、线别下拉、设备状态下拉、综合搜索、地域筛选、操作按钮
- 表格区域：显示设备列表或报警信息列表
- 分页区域：显示分页控件
- 弹窗区域：用于显示详情、编辑信息等

### 6.1 技术栈
