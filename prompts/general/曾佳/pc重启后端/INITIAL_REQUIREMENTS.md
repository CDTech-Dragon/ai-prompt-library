# 初始需求文档 (INITIAL_REQUIREMENTS.md)

## 1. 项目概述

PCM (PC Management) 后端系统是一个用于管理PC设备信息、重启记录和告警信息的Spring Boot应用程序。该系统提供RESTful API接口，支持多数据源访问，并具备完善的分页查询功能。

## 2. 核心功能需求

### 2.1 PC设备信息管理
- 提供PC设备信息的分页查询接口
- 支持设备信息的增删改查操作
- 设备信息包括：PC编号、名称、状态、配置等

### 2.2 告警信息管理
- 提供今日告警信息的查询接口
- 支持告警规则配置
- 支持告警信息的分页查询

### 2.3 重启记录管理
- 提供PC重启记录的查询接口
- 支持重启记录的分页查询

### 2.4 多数据源支持
- 支持配置和切换多个数据源
- 提供数据源切换的注解和AOP实现

### 2.5 静态资源处理
- 支持前端静态资源的访问
- 确保API接口不被静态资源配置拦截

## 3. 技术栈需求

### 3.1 后端框架
- Spring Boot 2.x
- MyBatis Plus
- Spring MVC

### 3.2 数据库
- MySQL 5.7+
- 支持多数据源配置

### 3.3 中间件
- Redis (可选，用于缓存)

### 3.4 开发工具
- Maven 3.x
- JDK 8+

## 4. 接口需求

### 4.1 PC设备信息接口
- `GET /api/pc/info/page` - PC设备信息分页查询

### 4.2 告警信息接口
- `GET /api/alarm/today` - 今日告警信息查询
- `GET /api/alarm/page` - 告警信息分页查询

### 4.3 重启记录接口
- `GET /api/reboot/page` - 重启记录分页查询

## 5. 性能需求

- API接口响应时间不超过500ms
- 支持并发请求数不低于100
- 分页查询默认每页50条数据

## 6. 安全需求

- API接口需要进行权限验证
- 防止SQL注入攻击
- 防止XSS攻击

## 7. 部署需求

- 支持Docker容器化部署
- 支持配置文件外部化
- 支持日志收集和监控

## 8. 文档需求

- API接口文档
- 技术架构文档
- 部署文档
- 开发手册

## 9. 维护需求

- 提供详细的日志记录
- 支持系统监控和告警
- 提供数据备份和恢复机制

- 所有功能模块按照需求实现
- API接口测试通过率100%
- 系统稳定性测试通过
