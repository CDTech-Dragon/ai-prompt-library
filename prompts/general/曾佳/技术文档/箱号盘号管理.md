## 一、项目概述

箱号盘号管理系统是一款面向生产场景的 Web 应用，核心目标是实现生产过程中箱号与编带盘号的规范化管理。系统集成扫码录入、数据管理、Excel 导出、标签打印及用户权限管控等功能，有效解决传统人工记录模式下的效率低、易出错、数据分散等问题，助力企业实现生产数据的数字化、标准化管理。

### 核心功能清单

- 扫码记录：支持扫码枪扫描或手动输入，自动生成流水号，重复记录检测
- 数据管理：多条件筛选查询、记录编辑 / 删除、分页展示
- 数据导出：按筛选条件导出 Excel 格式文件
- 打印功能：支持当前筛选数据及最近记录打印（80mm×60mm 标签格式）
- 用户管理：注册、登录、权限分配、账号启用 / 禁用
- 操作日志：记录关键操作行为，支持追溯

## 四、功能模块详解

### 4.1 扫码记录管理

#### 4.1.1 扫码录入

- 录入方式：支持扫码枪扫描条码（自动触发录入）或手动输入条码内容
- 流水号生成：系统自动生成唯一流水号，支持按基础箱号统计序号
- 重复检测：录入时自动校验，避免重复记录提交

#### 4.1.2 数据管理

- 记录展示：以表格形式展示扫码记录，支持分页加载
- 筛选查询：支持按机型、基础箱号、日期范围组合筛选
- 记录操作：支持对已有记录进行编辑（修改机型、箱号等信息）和删除

#### 4.1.3 数据导出

- 导出格式：Excel 文件（.xlsx 格式）
- 筛选导出：支持按机型、基础箱号筛选后导出目标数据
- 导出触发：前端点击 "导出 Excel" 按钮，后端生成文件并返回下载链接

#### 4.1.4 打印功能

- 打印范围：当前筛选条件下的所有数据、最近 4 条扫码记录
- 打印格式：固定 80mm×60mm 标签尺寸，适配热敏打印机等设备
- 操作流程：选择打印范围→预览→触发打印机输出

### 4.2 用户管理

#### 4.2.1 用户登录

- 验证逻辑：用户名 + 密码校验，密码通过 Bcryptjs 加密存储
- 日志记录：登录成功后记录操作用户、IP 地址、登录时间至日志表

#### 4.2.2 用户注册

- 注册流程：填写用户名、密码→系统加密存储→默认分配 "packer" 角色
- 权限控制：新注册用户默认启用，仅可操作自身录入的数据

#### 4.2.3 用户管理（管理员权限）

- 用户列表：查看系统所有注册用户信息
- 信息编辑：修改用户角色、用户名等信息
- 状态控制：支持启用 / 禁用用户账号（禁用后无法登录系统）

### 4.3 操作日志记录

- 记录范围：用户登录、数据录入、编辑、删除、导出、打印等关键操作
- 记录内容：操作用户、操作类型、操作描述、IP 地址、操作时间
- 用途：支持操作追溯，便于问题排查

## 五、API 接口说明

### 5.1 扫码记录接口

| 请求方法 | 接口路径                                  | 功能描述                             |
| -------- | ----------------------------------------- | ------------------------------------ |
| GET      | /api/scan-records                         | 获取所有扫码记录（支持筛选参数传递） |
| GET      | /api/scan-records/count                   | 获取指定基础箱号的记录数量           |
| GET      | /api/scan-records/max-sequence            | 获取指定流水号的最大序号             |
| GET      | /api/scan-records/count-by-sequence       | 获取指定流水号的记录数量             |
| POST     | /api/scan-records                         | 添加新的扫码记录                     |
| PUT      | /api/scan-records/:id                     | 更新指定 ID 的扫码记录               |
| DELETE   | /api/scan-records/:id                     | 删除指定 ID 的扫码记录               |
| GET/POST | /api/scan-records/export                  | 导出筛选后的扫码记录为 Excel         |
| GET      | /api/scan-records/model-types             | 获取系统中所有机型列表               |
| GET      | /api/scan-records/base-box-numbers        | 获取所有基础箱号列表                 |
| GET      | /api/scan-records/base-box-numbers/:model | 获取指定机型对应的基础箱号列表       |

### 5.2 用户接口

| 请求方法 | 接口路径       | 功能描述                                 |
| -------- | -------------- | ---------------------------------------- |
| POST     | /api/login     | 用户登录（返回登录状态及用户信息）       |
| POST     | /api/register  | 新用户注册                               |
| GET      | /api/current   | 获取当前登录用户信息                     |
| GET      | /api/users     | 获取所有用户列表（仅管理员可访问）       |
| PUT      | /api/users/:id | 更新指定 ID 的用户信息（仅管理员可访问） |
| DELETE   | /api/users/:id | 删除指定 ID 的用户（仅管理员可访问）     |

### 5.3 前端 API 调用示例

javascript

运行

```javascript
// 1. 获取所有扫码记录
export const getRecords = async (params) => {
  return await axios.get('/api/scan-records', { params });
};

// 2. 添加扫码记录
export const addRecord = async (data) => {
  return await axios.post('/api/scan-records', data);
};

// 3. 用户登录
export const login = async (userInfo) => {
  return await axios.post('/api/login', userInfo);
};

// 4. 导出Excel
export const exportExcel = async (filterParams) => {
  return await axios({
    url: '/api/scan-records/export',
    method: 'GET',
    params: filterParams,
    responseType: 'blob' // 二进制流格式（用于文件下载）
  });
};
```

## 八、使用指南

### 8.1 系统登录

1. 访问前端应用地址（如 http://<服务器 IP>）
2. 输入用户名和密码（初始管理员账号：admin /admin123）
3. 点击「登录」按钮，进入系统主页

### 8.2 扫码录入操作

1. 在系统主页点击「扫码录入」模块
2. 选择机型和基础箱号（或手动输入）
3. 使用扫码枪扫描编带盘号条码（或手动输入条码内容）
4. 系统自动填充流水号和创建时间，点击「确认录入」完成提交

### 8.3 数据管理操作

1. 进入「数据管理」模块，默认展示所有扫码记录
2. 使用筛选条件（机型、基础箱号、日期范围）筛选目标数据
3. 点击表格行可编辑记录，点击「删除」按钮可删除指定记录（管理员可删除所有记录，普通用户仅可删除自身录入记录）

### 8.4 数据导出操作

1. 在数据管理页面筛选出需要导出的数据
2. 点击「导出 Excel」按钮
3. 浏览器自动下载 Excel 文件，文件包含筛选结果的完整字段

### 8.5 打印操作

1. 筛选需要打印的数据（或直接使用默认数据）
2. 点击「打印当前数据」按钮，打印筛选后的所有记录
3. 点击「最近打印」按钮，打印最近录入的 4 条记录
4. 在打印机预览页面确认纸张尺寸为 80mm×60mm，点击「打印」

## 九、常见问题排查

### 9.1 扫码枪无法自动触发录入

- 检查扫码枪是否配置「自动添加回车键」功能（多数扫码枪默认开启，如需手动配置可参考设备说明书）
- 确保扫码输入框处于聚焦状态（点击输入框后再扫描）
- 检查扫码枪与设备的连接（USB 接口是否松动）

### 9.2 Excel 导出失败

- 检查浏览器是否阻止弹出窗口（导出功能依赖新窗口下载，需允许弹出）
- 确认设备磁盘空间充足（避免因空间不足导致下载中断）
- 排查网络连接（网络不稳定可能导致文件下载不完整）

### 9.3 打印格式不正确

- 确认打印机已设置为 80mm×60mm 标签纸
- 在浏览器打印预览中调整缩放比例（建议设置为 100%）
- 检查打印方向是否为「横向」（根据标签尺寸调整）

### 9.4 登录失败

- 检查用户名或密码是否输入正确（密码区分大小写）
- 确认账号状态是否为「启用」（管理员可在用户管理中查看）
- 排查后端服务是否正常运行（服务中断会导致登录验证失败）
