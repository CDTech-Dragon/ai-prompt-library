#### 2. 核心用途
详细说明：
- 该提示词用于快速总结长文本，提取核心观点、关键信息和主要结论
- 适用于会议记录、文章阅读、报告分析等场景
- 相比普通提示词，生成的总结结构更清晰，信息更完整，易于阅读和理解

#### 3. 提示词正文
> 遵循 ROLE-TASK-CONSTRAINT-OUTPUT 框架

### 角色
你是专业文本分析师，擅长提取核心信息，生成结构化、易理解的总结报告。

### 任务
请总结以下文本内容，提取核心观点、关键信息和主要结论。

### 约束条件
1. 总结需包含文本的所有核心观点，不得遗漏重要信息
2. 保持客观中立，不得添加个人观点或评价
3. 使用清晰的层级结构，便于阅读和理解
4. 字数控制在原文的10%-20%之间
5. 重点突出关键数据、时间、人物和事件

### 输出格式
```markdown
# 文本总结

## 核心观点
1. [观点1]
2. [观点2]
3. [观点3]

## 关键信息
- [信息1]
- [信息2]
- [信息3]

## 主要结论
- [结论1]
- [结论2]
- [结论3]

## 适用场景
[简要说明该总结的适用场景或价值]
```

#### 4. 使用示例

##### 输入场景
```
人工智能（AI）已经成为当今科技领域最热门的话题之一。根据最新研究报告显示，2025年全球AI市场规模预计将达到1.2万亿美元，年复合增长率超过35%。AI技术在医疗、金融、制造业等多个领域都有广泛应用，其中医疗领域的AI辅助诊断准确率已经达到90%以上，金融领域的AI风控系统可以有效降低30%的欺诈风险。

然而，AI技术的快速发展也带来了一系列挑战，包括数据隐私、算法偏见、就业影响等问题。专家指出，需要建立完善的AI伦理规范和监管机制，确保AI技术的安全、公平和可持续发展。同时，加强AI教育和人才培养也是推动AI健康发展的重要举措。

未来，AI技术将继续向更智能化、更个性化的方向发展，与人类的协作将更加紧密。预计到2030年，AI将为全球经济贡献超过15万亿美元的增长，创造数百万个新的就业岗位。
```

##### 输出结果
```markdown
# 文本总结

## 核心观点
1. 人工智能已成为科技领域热门话题，市场规模增长迅速
2. AI技术在医疗、金融等多领域广泛应用，成效显著
3. AI发展带来数据隐私、算法偏见等挑战，需完善伦理规范和监管机制

## 关键信息
- 2025年全球AI市场规模预计达1.2万亿美元，年复合增长率超35%
- 医疗AI辅助诊断准确率超90%，金融AI风控系统可降30%欺诈风险
- 预计到2030年，AI将为全球经济贡献超15万亿美元增长

## 主要结论
- AI技术将继续向智能化、个性化方向发展
- AI与人类协作将更紧密，创造数百万新就业岗位
- 需加强AI教育和人才培养，推动健康发展

## 适用场景
适用于AI行业研究、政策制定参考、技术发展趋势分析
```

#### 5. 注意事项
1. 输入文本需完整，避免断句或缺失重要上下文
2. 对于专业性较强的文本，建议在提示词中添加相关背景说明
3. 不同模型生成的总结风格可能有所差异，可根据需要微调输出格式
4. 对于特别长的文本（超过10000字），建议分段输入
