# 电脑行为统计提示词 - v1.0.0
> 简短描述：用于生成电脑行为统计系统的解决方案，包括死机重启、非法使用USB和互联网行为监管

#### 1. 基础信息
| 字段         | 内容                          |
|--------------|-------------------------------|
| ID           | prompt-general-pc-behavior-001 |
| 适用模型     | GPT-4, Claude 3, 通义千问     |
| 难度等级     | 进阶                          |
| 创建时间     | 2025-11-20                    |
| 最后更新时间 | 2026-01-04                    |
| 作者         | prompt-library-contributors   |

#### 2. 核心用途
详细说明：
- 该提示词用于分析生产拉测试电脑的行为问题，生成电脑行为统计系统解决方案
- 适用于制造业电脑终端管理、安全监管、生产效率优化等场景
- 相比普通提示词，包含了完整的需求分析、数据来源和功能要求，便于生成更精准的解决方案

#### 3. 提示词正文
> 遵循 ROLE-TASK-CONSTRAINT-OUTPUT 框架

### 角色
你是资深IT资产管理系统架构师，擅长制造业电脑终端管理和安全监管系统设计。

### 任务
请根据以下需求，设计一个电脑行为统计系统的解决方案，包括数据采集、处理、存储和前端展示。

### 约束条件
1. 支持对电脑死机重启、非法使用U盘、非法接入互联网的行为监测
2. 实现超过阈值自动产生问题条的功能
3. 支持实时监测和定期数据上报
4. 前端需醒目显示违规记录
5. 需与其他系统实现管理追踪闭环

### 输出格式
```markdown
# 电脑行为统计系统解决方案

## 1. 问题分析
- **现象**：生产拉测试电脑频繁死机重启，严重影响生产效率；存在非法使用USB和互联网的安全隐患
- **原因**：测试软件问题；电脑设置问题；电脑本身故障；非法行为未受控执行

## 2. 系统设计

### 2.1 数据采集层
- **设备信息**：从K3实际库获取电脑配置、位置等基础信息
- **行为数据**：通过PC Monitor Client.exe客户端采集故障重启、非法使用U盘、非授权互联网登录信息
- **采集周期**：实时监测数据以60S为周期返回服务端

### 2.2 数据处理层
- 对采集的数据进行去重和聚合处理
- 累计重启次数并呈现于前台
- 将相关信息与唯一资产编码对应关联
- 生成异常告警数据，触发条件逻辑

### 2.3 数据存储层
- **资产及行为信息库**：pcmo_datas（包含IP、MAC、CPU型号、责任人、位置、更新时间等）
- **白名单库**：gateway_info（包含责任人、IP、MAC、网络权限、更新时间等）
- **存储位置**：192.168.10.130 中的 pcmonitor 数据库

### 2.4 前端展示层
- **数据统计报表**：展示电脑行为统计数据
- **违规告警**：醒目红色告警显示违规记录
- **消息通知**：后期实现将告警呈现于主页的消息通知栏

### 2.5 系统功能
- 集中监测连网电脑终端的U盘使用和网络连接状态
- 超过阈值自动产生问题条，启动专项问题管理
- 与其他系统（如DOC\OA等）实现管理追踪闭环

## 3. 技术实现
- 客户端：PC Monitor Client.exe，支持实时监测和定期上报
- 后端服务：处理所有记录并去重，累计重启次数
- 数据存储：集中存储于192.168.10.130的pcmonitor数据库
- 前端展示：醒目红色告警显示违规记录，支持消息通知

## 4. 预期效果
- 减少电脑死机重启对生产效率的影响
- 有效监管非法使用USB和互联网的行为
- 实现超过阈值自动产生问题条的功能
- 提高电脑终端的管理效率和安全性
- 与其他系统形成管理追踪闭环
```

#### 4. 使用示例

##### 输入场景
请根据以上提示词，设计一个电脑行为统计系统的详细方案。
