#### 3. 提示词正文
> 遵循 ROLE-TASK-CONSTRAINT-OUTPUT 框架，针对GPT-4优化

### 角色
你是资深软件架构师，擅长代码优化和重构，特别熟悉GPT-4模型的能力特点。

### 任务
请针对以下代码进行全面优化，生成高质量的改进建议和优化后的代码。

### 约束条件
1. 充分利用GPT-4的上下文理解能力，深入分析代码逻辑
2. 优化建议需包含性能、可读性、可维护性三个方面
3. 输出格式需结构化，便于阅读和实施
4. 针对GPT-4优化，确保生成的代码格式正确，无需额外调整
5. 支持多种编程语言，包括Python、JavaScript、Java、C++等
6. 提供优化前后的代码对比
7. 解释每一处优化的原因和预期效果

##### 输出结果
```markdown
# 代码优化报告

## 原始代码
```python
def calculate_sum(numbers):
    result = 0
    for i in range(len(numbers)):
        result += numbers[i]
    return result

# 使用示例
nums = [1, 2, 3, 4, 5]
print(calculate_sum(nums))
```

## 优化建议

### 1. 性能优化
- 使用Python内置的sum()函数替代手动循环，内置函数经过C语言优化，性能更优

### 2. 可读性优化
- 简化函数实现，减少代码行数，提高可读性
- 添加函数文档字符串，说明函数用途和参数

### 3. 可维护性优化
- 保持函数名称的语义化，便于理解
- 支持类型提示，提高代码的可维护性和IDE支持

## 优化后代码
```python
def calculate_sum(numbers: list[int]) -> int:
    """
    计算列表中所有元素的和
    
    Args:
        numbers: 包含整数的列表
    
    Returns:
        列表元素的总和
    """
    return sum(numbers)

# 使用示例
nums = [1, 2, 3, 4, 5]
print(calculate_sum(nums))
```

## 优化效果分析
- 性能提升：预计提升50%-80%（内置sum函数比手动循环更高效）
- 代码行数变化：从6行减少到11行（增加了文档字符串，实际核心代码从4行减少到1行）
- 复杂度变化：从O(n)降低到O(n)（时间复杂度相同，但常数因子更小）
```

#### 5. 注意事项
1. 该提示词专为GPT-4和GPT-4 Turbo优化，在其他模型上可能需要调整
2. 对于特别复杂的代码，建议分段输入，充分利用GPT-4的上下文理解能力
3. 可以根据需要调整输出格式，例如添加更多的优化维度
4. 对于大型项目的代码优化，建议先进行模块化分析，再逐模块优化
